# Country flags

Local 4:3 SVG flags from [lipis/flag-icons](https://github.com/lipis/flag-icons), commit `ac7e0eb3259eb62aa6100c435607e2fe03896a97`. Distributed under the included MIT license. Original SVG artwork is unchanged.

Only the displayed country assets are requested by the browser; no remote flag service or icon framework is loaded. Unknown codes keep the country label without a fabricated flag.
