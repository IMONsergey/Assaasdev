# Interface icons

Source: https://github.com/tabler/tabler-icons/tree/main/icons/outline

The interface uses original Tabler outline SVGs, downloaded 2026-10-24. They share a 24 px grid and consistent 2 px strokes. `currency-token.svg` is a locally drawn icon on the same grid for cryptocurrency actions. The original brand mark remains the supplied APCOSYS Figma asset.

SVGs are rendered as CSS masks so their color follows the current theme. See `TABLER-LICENSE.txt` for the upstream MIT license.
