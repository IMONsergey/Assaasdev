# APCOSYS avatars

The client supplied these 20 SVG characters in `Apcosys (8).zip` on 24 October 2026.
Each SVG is copied without changes; the stable public filenames are mapped to the
original filenames and SHA-256 values in `source-manifest.json`.

The application serves the SVGs as local image files. It does not embed SVG markup
from storage or fetch user-provided image URLs. Selection is a device preference,
isolated by the authenticated user ID; the existing profile API has no avatar field.
