## Additional product, provider and operating-system marks

The 34 SVGs under `marks/` are copied without changes from Simple Icons 16.35.0, pinned at commit `ed9a5192b24ad2f169bf1009931da0df27d5a49a`. Each icon retains its original viewBox and vector path. The UI uses their monochrome silhouettes at the collection's recorded brand color (Linux and very dark marks use the current text color for contrast). Original direct-source links, brand guidance and any icon-specific license metadata are retained in `marks/sources.json`; collection license and disclaimer are included alongside the SVGs. Debian and PHP artwork retain their CC-BY-SA source attribution in that manifest.

Only actual returned product, operating-system or organization names select a branded mark. A protocol name never creates evidence of a detected product, and a port number is never used to infer a protocol or brand. Unknown names use a neutral semantic icon. All assets load locally; no logo service, tracking pixel, font or entire icon library is fetched by the client.
