## Новые законченные цепочки действий

### История поиска

Отдельная страница `/search/history`, доступная из поиска и Workspace settings. Записи сгруппированы по времени; есть поиск по истории, Public/Private и периоды 7/30/90 дней. Записываются выполненные запросы, включая вложенные условия и диапазоны. Повторные страницы одного запроса не создают отдельные записи.

**Restore** открывает редактируемый draft без запроса к поиску. **Run** выполняет один явный запрос. Сохраняются private task scope и допустимый возврат в Scanner. Есть удаление записи, подтверждаемая очистка, Undo и пауза записи. Изменение в соседней вкладке учитывается при возвращении на страницу.

Хранилище разделено по аккаунту, ограничено 100 записями и 90 днями. Гостевые запросы, shared-access tokens и секреты не сохраняются. Повреждённые или чрезмерные данные отбрасываются; отсутствие localStorage не выдаётся за успешное постоянное сохранение.

### Собственный аватар

В профиле можно выбрать один из 20 существующих аватаров либо загрузить PNG, JPEG или WebP до 5 MB. Файл проверяется до декодирования, затем обрезается по центру и перекодируется с размером до 512 px. Исходные метаданные не переносятся.

Предусмотрены preview, Cancel, Use avatar, замена, удаление фото и возврат к пресету. Неуспешная загрузка сохраняет прежний аватар. Изображение применяется к профилю и меню пользователя, сохраняется для этого аккаунта в текущем браузере. Серверный API профиля не подменён локальным хранилищем.

### Оплата из кошелька

Цепочка: **выбор пакета → review заказа и остатка → Pay with balance → processing/pending → подтверждённая квитанция → Payments**. Цена находится в карточке и заказе, кнопка обозначает действие.

Недостаток средств, отказ, таймаут, несовпадающий payment ID и поздний ответ после ухода со страницы имеют отдельные состояния. Незавершённая live-оплата блокирует повторное списание после SPA-перехода и перезагрузки вкладки. Даже если ID ещё не пришёл, попытка остаётся незавершённой до проверки. Запись оплаты нельзя удалить в процессе восстановления.

Подтверждение платежа не приравнивается к обновлению аккаунта: при устаревшем снимке квитанция показывает обновление баланса, а кнопка Refresh account проверяет его повторно. Презентационный адаптер изменяет только собственные данные в памяти и завершает списание один раз. Никакие реальные платёжные провайдеры или кошельки в этой проверке не вызывались.

При проверке опубликованной версии обнаружено расхождение: новый поиск имел текущую дату, а новый платёж — дату первоначальных fixtures. Исправлен источник времени презентационного адаптера. Новые действия используют часы браузера; начальные даты аккаунта и workspace получают один общий момент отсчёта с сохранением относительных интервалов. Запись счёта и ответ API используют одинаковые `issuedAt/expiresAt`, а подтверждение — один момент расчёта. Исторические наблюдения хостов, файлов и индекса не сдвигаются. Проверены точная граница истечения, отсутствие списания после истечения, повторное подтверждение и повторный вход. Снимки `clock-history-current-date.png` и `clock-wallet-current-date.png` показывают один браузерный проход с датой 24 октября, 15:30.

### Онбординг

Каталог содержит **51 сценарий**. Добавлены реальные цепочки `search-history`, `manage-search-history`, `upload-avatar`, `wallet-payment` и `pivot-from-host`. Запуск сценария сам по себе не выполняет платёж, поиск, сохранение или очистку.

Сценарии наблюдают нужные действия и переходы: Cancel не засчитывается как сохранение аватара, Clear требует подтверждения, Restore и pivot ожидают отдельный Run, кошелёк ожидает подтверждённую квитанцию. На desktop guide располагается рядом с диалогом при наличии места. На mobile он занимает собственную строку между прокручиваемым содержимым и футером; при вводе текста становится компактным. Проверено короткое окно 320 × 640.

Подсветка относится к конкретному небольшому контролу. Обводка всей страницы и повторение инструкции убраны. Сохраняются явные состояния observed/reviewed/skipped — прохождение не выдаётся за действие, которое пользователь не совершал.

### Страница 404

Неизвестные адреса workspace, включая неизвестные подстраницы Billing, Scanner и Account, открывают одну страницу восстановления с Back to search и Go back.

Три игры связаны с исследованием: **Signal** — найти скрытый узел по расстояниям; **Route** — проложить путь с Undo и клавиатурным управлением; **Memory** — повторить короткую последовательность узлов. Игры начинаются явно, не используют WebGL, аудио или новые библиотеки. Таймеры очищаются при смене игры и уходе со страницы; системное уменьшение анимации учитывается. Интерактивные ячейки остаются не меньше 44 px на ширине 320 px.

## Сравнение с текущим сайтом клиента

Исследована публично доступная часть [apcosys.net](https://apcosys.net/): поиск, фильтры и распределения, карточка хоста, детали HTTP-ответа, тарифы, пакеты и публичная информация о способах оплаты. Снимки исходных экранов сохранены в `source/`. Закрытые операции аккаунта без авторизации не объявляются проверенными на клиентском сервере; для них использованы предоставленный контракт и контролируемые HTTP/WebSocket fixtures.

| Обнаруженное расхождение | Реализация |
|---|---|
| Поиск по значению внутри карточки хоста | Рядом с протоколом, портом, статусом, title, HTTP headers и доступными хешами добавлен переход в точный draft. Сохраняется контекст private search. JSON-кавычки title и динамические имена headers поддерживаются также локальным matcher. |
| Полный набор пакетов | Презентационная таблица приведена к семи опубликованным пакетам: 25k/$50, 85k/$150, 200k/$300, 350k/$450, 535k/$600, 750k/$750, 1M/$900. Live-цены по-прежнему приходят из API. |
| Годовой Business по счёту | Request invoice открывает редактируемую форму поддержки с Billing и предварительно заполненным контекстом. Обращение не отправляется автоматически. |

Порядок и включение аналитических распределений уже поддерживались; этот сценарий не был ошибочно записан как новый. Сопоставление исходных требований с 38 маршрутами приёмки остаётся в [предыдущей матрице](../2026-10-23-scenario-coverage.md).

## Граница готовности

Интерфейс и презентационные цепочки доступны для клиентского просмотра. История и загруженные аватары пока относятся к этому браузеру; синхронизация между устройствами требует серверного расширения. Полная перезагрузка презентационной версии создаёт свежие платёжные fixtures. Настоящие списания, почтовая доставка, внешняя авторизация и платные серверные операции требуют отдельной интеграционной приёмки с backend. Подробности — в [implementation coverage](../../IMPLEMENTATION-COVERAGE.md).
