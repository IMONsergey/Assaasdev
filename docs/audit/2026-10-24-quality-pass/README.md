## Границы вывода «5 из 5»

Пять баллов не присваиваются автоматически по числу исправлений или тестов. Этот проход подтверждает конкретные критерии интерфейса на проверенной сборке. Из исходной анкеты остаётся отдельная проверка с новыми пользователями: первый поиск → фильтр → host/service → сохранение/возврат, понимание тарифа и расхода без подсказок автора.

Публичное demo не подтверждает live email/2FA, фактические платежи, доступы настоящего backend, актуальность индекса и нагрузочную производительность. Files/Buckets использует ограниченный кэш в памяти — до пяти неактивных записей плюс текущий запрос. Он очищается при смене аккаунта/выходе и не является постоянным хранением: полная перезагрузка восстанавливает параметры, а новый поиск запускается явно. Полный WCAG-аудит и кроссбраузерная сертификация этим отчётом не заявляются.
